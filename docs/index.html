01 / How it works

One sentence in. A living scene out.

A

Claude / MCP client

Claude Desktop, Claude Code, Cursor or any stdio MCP client.

stdio · MCP
B

cavalry-mcp

A Node.js server that schema-checks every argument before it reaches Cavalry.

HTTP · 127.0.0.1
C

Cavalry bridge

One plain JavaScript file running inside Cavalry on its built-in WebServer.

28

Typed tools

Every argument is validated, and attribute paths are checked before writes. Arbitrary code execution is off by default.

127.0.0.1

Local only

The bridge binds to localhost and makes no outbound calls. Your scenes never leave your machine.

1

Batch round-trip

cavalry_batch builds whole rigs in one call, with $0-style references to layers made earlier.

0

Dependencies in Cavalry

Copy one script into the Scripts folder and press start. Clear errors tell you exactly what to fix.

03 / Install

Three steps. About two minutes.

You need Cavalry 2.7 or later (free for individuals) and Node.js 22 LTS.

  1. 01

    Build the server

    git clone https://github.com/Pinyi333/cavalry-mcp.git
cd cavalry-mcp
npm install
  2. 02

    Start the bridge in Cavalry

    Copy bridge/cavalry-mcp-bridge.js into Cavalry's Scripts folder (Help > Scripts), then run Window > Scripts > cavalry-mcp-bridge. The panel shows "Listening on 127.0.0.1:37650".

  3. 03

    Connect your client

    {
  "mcpServers": {
    "cavalry": {
      "command": "node",
      "args": ["/ABSOLUTE/PATH/TO/cavalry-mcp/dist/index.js"]
    }
  }
}
    claude mcp add cavalry -- node /ABSOLUTE/PATH/TO/cavalry-mcp/dist/index.js
    // ~/.cursor/mcp.json
